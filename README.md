# Instaloader

Repositório de código relacionado ao projeto Instaloader.

## Sobre

Este repositório contém uma versão mantida neste espaço do projeto Instaloader. Consulte o histórico de commits e os arquivos do código para identificar as diferenças em relação ao projeto original e os requisitos desta versão.

## Começando

```bash
git clone https://github.com/kaikybrofc/instaloader.git
cd instaloader
```

Confira os arquivos de dependências e a documentação existente para instalar os requisitos e executar os comandos compatíveis com esta versão.
